## The word

**ghosting**

Home Wi-Fi that vanishes mid-call, mid-download, mid-sentence — present one
second, gone the next, no explanation, no goodbye. The signal doesn't just
get slow; it ghosts you.

## How it works

`main.py` writes the single word to `/output/entry.txt`. Nothing else: no
network, no input, no dependencies beyond the Python standard library.

```sh
python3 main.py
cat /output/entry.txt   # ghosting
```
